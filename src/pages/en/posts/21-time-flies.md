## Interesting Tools

**HTTP Status Cats**  
<https://http.cat>  
Uses cute kitties to playfully represent HTTP status codes—super fun~~  
<img src="https://gz-blog-storage-1252787757.cos.ap-guangzhou.myqcloud.com/weekly/2024/11/21interestingtoolshttpcodes.jpg" width="800" />

**PVE Helper Scripts Refactoring**  
<https://github.com/community-scripts/ProxmoxVE>  
The maintainers completely refactored this project—huge thumbs up!  

**Healthchecks**  
<https://github.com/healthchecks/healthchecks>  
Supports multiple health-check scenarios like cron jobs, resource monitoring, pings, and more.  
<img src="https://gz-blog-storage-1252787757.cos.ap-guangzhou.myqcloud.com/weekly/2024/11/21interestingtoolscronjobmonitoring.jpg?imageMogr2/format/webp" width="800" />

**Hitomi-Downloader**  
<https://github.com/KurtBestor/Hitomi-Downloader>  
A desktop downloader supporting various video platforms. Hasn't been updated in a while; unearthed it from my GitHub starred repos.  

**Deep-Live-Cam**  
<https://github.com/hacksider/Deep-Live-Cam>  
An insanely powerful live camera tool that can instantly morph you into Elon Musk.  

**3D Printer Resources**  
<https://jbp3d.com>  
A website aggregating tons of 3D printing assets and models.  
<img src="https://gz-blog-storage-1252787757.cos.ap-guangzhou.myqcloud.com/weekly/2024/11/21interestingtools3dresource.jpg?imageMogr2/format/webp" width="800" />
