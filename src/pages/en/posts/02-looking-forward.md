## Learning

**Calligraphy**  
I've actually had a calligraphy habit for a long time, but slacked off earlier this year. Recently sorted through my old copybooks, so getting back into daily practice today~~  
My practice sequence for Chinese calligraphy is Regular Script (Kaishu) -> Semi-cursive (Xingkai) -> Running Script (Xingshu). Not sure if that's the canonical path, but that's how I'm rolling with it.  
For English calligraphy, I chose Italic script. The copybook I bought after starting work was from a different publisher than the one I used in high school/college, and the results definitely didn't look as nice. Highly recommend Yu Peian's copybooks. Dug up a practice sheet from 2014 on Facebook—pretty sure I can't write that neatly anymore.
